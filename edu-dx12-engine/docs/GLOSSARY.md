# 用語を最初に説明するための言い換え

これは教材を書くときの補助表。各章で初出なら、本文でも一言の説明を添える。比喩を使った後に、実際の責務・寿命へ戻る。

| 用語 | 学生向けの一言 | 取り違えを避ける補足 |
| --- | --- | --- |
| Device | GPUの機能を使うための窓口 | GPUで動く処理本体ではない |
| Command list | GPUへの作業手順書 | 記録しただけでは実行されない |
| Command queue | 手順書をGPUへ送る受付 | 同じqueue内の順序とCPUの進行は別 |
| Command allocator | 手順書を記録するための記憶領域 | GPUが読む間はResetできない |
| Fence | GPUが終えた仕事を示す通過番号 | CPUが番号を書くだけでGPU完了にはならない |
| Swap chain | 描く画面と見せる画面を交替する仕組み | 各back bufferの状態・寿命を管理する |
| Back buffer | 次に表示するための描画先画像 | present前後の状態遷移が必要 |
| Resource barrier | GPU資源の使い方が変わる境目の宣言 | 単なるC++変数の書換えではない |
| Descriptor | GPU資源の見方を説明する札 | 資源データそのものではない |
| Descriptor heap | 札を並べて置く場所 | GPU利用中の札を勝手に再利用しない |
| RTV / DSV | 色を書込む札 / 奥行きを読む・書く札 | SRVやCBVとは用途が違う |
| SRV / CBV / UAV | 通常読取 / 定数読取 / 自由な読書きの札 | 読書きの制約と状態を対応させる |
| Root signature | shaderへ何をどこから渡すかの約束表 | HLSLのregisterとCPU設定を一致させる |
| PSO | 描画設定をまとめた組み合わせ | shaderだけでなく形式やblend等も含む |
| Upload heap | CPUからGPUへ渡すデータの置き場 | Map後にすぐ上書きしてよいとは限らない |
| Frame context | 一回分の描画作業に必要な道具箱 | swap chainの画像indexと常に同じ概念ではない |
| Render pass | 一つの目的で行う描画のまとまり | DX12の専用RenderPass API利用を必須とはしない |
| RenderGraph | 描画の段取りと資源利用を見渡す表 | 初期版の機能範囲を明記する |
| Node | ゲーム世界を階層で組み立てる部品 | GPU資源を全部所有する万能クラスにしない |
| Scene | 一つの動作するNodeツリーの実行単位 | 素材テンプレートと実行中状態を分ける |
| Resource | 複数の場所から使える素材データ | Sceneの親子所有と同一視しない |
| Handle | 有効性を確認して相手を探す引換券 | 生ポインタを別名にしただけでは安全にならない |
| RAII | 寿命に合わせて取得と後片付けを組にする方法 | GPU非同期処理の完了まで保証する仕組みではない |
| Unlit | 光の計算をせずに素材の色を表示する描画 | 色空間の変換は依然必要 |
| PBR | 材質と光の振る舞いを物理に沿って近似する描画 | 名前だけで反射・影・IBLが全て揃うわけではない |
| BRDF | 光が表面からどちらへどれだけ返るかの関数 | 入射光や距離減衰そのものと分ける |
| Linear / sRGB | 光の量として扱う値 / 表示・保存向けに変換した値 | RGBの色とroughness等の数値データを区別する |
| Tone mapping | 大きな光の値を画面で見える範囲へ収める変換 | sRGB変換と同じ処理ではない |
| Debug layer | DX12の使い方の誤りを知らせる検査役 | 実行結果の正しさを全て証明しない |
| GPU-based validation | GPU実行時の資源利用も調べる追加検査 | 重くなるため調査時に使い分ける |
| PIX | GPUへの命令と時間を調べる観察道具 | capture条件や使用版を記録する |

APIの厳密な意味は[REFERENCES.md](REFERENCES.md)のMicrosoft等の一次資料を参照する。語彙表の比喩は本プロジェクトの教育上の表現である。
