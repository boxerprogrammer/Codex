# Codexへ渡す継続プロンプト

初回のM00が終わった後に使います。`到達段階`だけを希望に合わせて置き換えてください。

```text
$build-educational-dx12-engine

[開発モード]
到達段階：M02（DX12で背景色を描き、終了・最小化・復帰・リサイズを確認する）

AGENTS.md と docs/STATUS.md を読み、実装と検証の現在地を確認してください。ROADMAPの依存順に従い、到達段階まで必要な作業を実装・検証・記録してください。

完了済みの段階を最初から作り直さず、未検証の前提があれば先に解消してください。Windows環境が使えない部分は実装済み・検証待ちとして扱ってください。

重要な新規設計だけ2〜3案で比較し、推奨案で進めて判断を記録してください。既に許可した範囲内の段階ごとに確認を求める必要はありません。

動作する最小サンプルと、関係する故障リスクを確認してください。全機能・全ライブラリの実装を前倒ししないでください。教材本文はまだ作らず、学習の要点・よくあるミスを短く記録してください。

終了時に変更の目的、ファイル、ビルドと実行結果、未検証、次の段階をまとめ、docs/STATUS.mdを更新してください。
```

例：Node構造を進めるならM05、PBR比較までならM08を指定します。範囲が大きい場合も、各段階の受入条件を順に満たして進みます。
