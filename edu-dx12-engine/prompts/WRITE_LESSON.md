# Codexへ渡す教材化プロンプト

```text
$build-educational-dx12-engine

[教材執筆モード]
対象段階：M02
対象学生：C++のクラス・ポインタ・継承・STL基礎は既習。DX12は初学者。
授業単位：90分×2コマを目安に、必要なら分割する。

AGENTS.md、docs/STATUS.md、docs/CURRICULUM.md、LESSON_TEMPLATE.md、EXERCISE_TEMPLATE.mdを読み、対象の実装・実行証跡を確認してください。

既に存在する実コードを根拠に教材を作り、ファイル名・シンボル・処理順を一致させてください。対象実装がまだない場合は、それを示して授業構成案まで作り、架空の完成コードや検証結果は書かないでください。

学生向けの章を lessons/students/ に、演習解答・採点基準・授業運営メモを lessons/teachers/ に別ファイルとして作ってください。学生へ配布する範囲が分かるようにしてください。

構成は、学習目標／なぜ必要か／小さなMermaid図／段階的実装解説／よくあるミスとデバッグ／基本の穴埋め・改変／発展の自力実装／自分の言葉で説明するチェックです。

専門用語は初出で一言言い換えてください。コードはC++20、HLSLは対応するshaderから引用し、省略箇所と未実施の検証を明示してください。命令を記録することとGPUが実行を終えることを区別してください。

教材本文を書く依頼です。エンジンの設計を黙って大きく変えないでください。教材を成立させるための小さな明確な不具合が見つかった場合は、その根拠を示して必要な修正と確認を行い、教材との対応を保ってください。
```
